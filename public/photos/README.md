# photos 폴더 구조 안내

## 폴더 명명 규칙

```
public/photos/
└── {단지 한글명}/          ← busan.json의 photos_folder 값과 일치
    └── {동 번호}/          ← 숫자만 (예: 101, 102)
        ├── 101 30.jpg      ← "{동} {높이m}.jpg" 형식
        ├── 101 60.jpg
        └── 101 90.jpg
```

## 파일명 규칙

| 형식 | 예시 |
|------|------|
| `{동번호} {높이}.jpg` | `101 30.jpg` |
| `{동번호} {높이}.jpeg` | `102 60.jpeg` |
| `{동번호} {높이}.png` | `103 90.png` |

- 높이 단위: m (숫자만 적어도 됨, m 자동 추가)
- 공백 대신 언더스코어도 허용: `101_30.jpg`
- 지원 확장자: `.jpg` `.jpeg` `.png`

## 단지 추가 흐름

1. `photos/{단지명}/` 폴더 생성
2. 동 폴더(`101/`, `102/` ...) 생성 후 사진 넣기
3. `배포.bat` 더블클릭 → scan → git push → Cloudflare 자동 배포
